# 存图

## 1.功能说明

存图可以在检测过程中自动保存原始图像和带有结果的截图，便于问题追溯、仿图和数据存档。

程序可以保存两种类型的图片：

- **原图 (Raw Image)**：从相机直接采集到的、未经任何处理的原始图像。
- **截图 (Snapshot Image)**：经过检测算法处理后，叠加了检测框、缺陷标记、测量数据等图形结果的图像。

## 2.配置存图

您可以根据生产需求，灵活地配置存图功能的各项参数。程序默认会开启原图和截图的存储。

在导航栏中，选择工具-选项，打开存图设置页面。可以单独针对原图和截图进行配置设置：

- **功能开关**：勾选此项可开启对应类型图片的保存功能。
- **结果**：您可以决定在什么情况下才保存图片：
  - ALL：保存每一次运行的图片（无论结果是OK还是NG）。
  - OK：**仅**在检测结果为 **OK** 时保存图片。
  - NG：**仅**在检测结果为 **NG** 时保存图片。
- **格式**：您可以选择图片的保存格式：
  - jpg：压缩率高，文件体积小，适用于大量存档。
  - png：无损压缩，图片质量高，但文件体积较大。
  - bmp：无压缩，文件体积最大，保留最完整的图像信息。
- **保存位置**：程序会显示一个默认的根目录（项目文件夹下的 Images 目录）。您可以点击浏览按钮，自定义一个全局的存图根目录。点击打开按钮，可以快速打开**当前活动任务**对应的存图文件夹。

配置完成后，点击【**保存**】按钮使设置生效。

## 3.图像信息

**目录结构**

- 所有图片都保存在您设置的“保存位置”根目录下。
- 程序会自动创建以**任务名称**命名的子目录。
- 在每个任务目录内，会再创建“**Raw**”和“**SnapShot**”两个子目录，分别存放对应类型的图片。
- **示例路径**：`D:\ProjDir\Images\Model-A-TopSide\SnapShot\`

**文件名规则**

- 为了保证每一张图片都有唯一的、信息丰富的身份标识，文件名经过了精心设计，格式如下：
  `{运行ID}_{时间戳}_{曝光参数}_{检测结果}_{序号}.jpg`
- **示例文件名**：`SN12345_20251118103000123_5000_OK_1.jpg`
