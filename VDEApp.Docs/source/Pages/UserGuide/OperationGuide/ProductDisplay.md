# 产品显示

## 1. 产品显示概述

产品显示系统是VDEApp的核心功能之一，专门用于实时监控和展示生产过程中的产品图像和数据。该系统采用模块化设计，支持灵活的布局配置和多任务监控。

![产品显示系统架构](/Image/Display/Product_display_system_architecture.png)

主要功能特点：
- 支持自定义网格布局（最多5×5）
- 实时显示生产过程中的图像记录
- 支持多任务、多节点同时监控
- 缺陷图像自动提取和展示
- 支持记录重命名和状态追踪

## 2. 产品显示布局管理

### 2.1 预设布局选择

在产品显示主界面顶部，您可以通过分段控件快速选择预设布局：

![预设布局选择](/Image/Display/Preset_layout_selection.png)

- **1×1布局**：单窗口显示，适合详细查看单个记录
- **2×2布局**：四窗口显示，适合同时监控多个关键点
- **自定义布局**：根据实际需求创建个性化布局

### 2.2 自定义布局设置

点击"Custom Layout"选项，打开布局设置窗口：

![自定义布局设置](/Image/Display/Custom_layout_settings.png)

操作步骤：
1. 在弹出的布局设置窗口中，通过数字选择器设置行数和列数（1-5行/列）
2. 点击"确认"按钮应用新布局
3. 系统会自动调整显示区域，创建对应数量的显示窗口

> **注意**：布局更改后，所有现有绑定关系将被保留，但可能需要重新排列以获得最佳显示效果。

### 2.3 布局保存与恢复

系统会自动保存您的布局配置：
- 布局设置保存在项目配置文件中
- 下次打开项目时自动恢复上次使用的布局
- 支持通过"显示"菜单中的"Show record configuration"重新设置布局

## 3. 显示记录绑定

### 3.1 绑定操作流程

每个显示窗口都需要绑定到特定的任务、节点和记录：

![绑定操作流程](/Image/Display/Binding_operation_process.png)

操作步骤：
1. 在未绑定的显示窗口上右键点击
2. 选择"打开显示绑定窗口"选项
3. 在绑定窗口中选择：
   - **任务名称**：选择要监控的任务
   - **节点名称**：选择任务中的特定节点
   - **记录名称**：选择要显示的具体记录
4. 设置**显示名称**（可选，默认为记录名称）
5. 点击"确认绑定"按钮完成操作

### 3.2 绑定窗口详解

![绑定窗口界面](/Image/Display/Binding_window_interface.png)

绑定窗口各区域功能：
- **任务选择下拉框**：列出当前项目中的所有任务
- **节点记录树**：以树形结构显示选中任务的所有节点和记录
- **显示名称输入框**：自定义显示在窗口标题栏的名称
- **刷新按钮**：重新执行选中任务以更新记录列表

> **提示**：如果记录列表为空或不完整，点击刷新按钮重新执行任务以获取最新记录。


## 4. 记录重命名


为了便于识别，可以自定义记录的显示名称：

操作方法：
1. 双击已绑定窗口的标题栏
2. 标题栏变为可编辑状态
3. 输入新的显示名称
4. 按Enter键确认或点击其他区域取消

![记录重命名](/Image/Display/Record_renaming.png)

> **注意**：重命名仅改变显示名称，不会影响实际记录的存储名称和路径。



## 5. 状态监控与反馈

### 5.1 绑定状态指示

每个显示窗口都有绑定状态指示：

![绑定状态指示](/Image/Display/Binding_status_indication.png)

- **链接图标**：已成功绑定并正常显示
- **未链接图标**：未绑定或绑定配置错误

### 5.2 刷新状态显示

窗口右上角的状态指示器显示刷新状态：

- **绿色圆点**：记录已更新到最新版本
- **红色圆点**：记录需要刷新或刷新失败

### 5.3 未绑定窗口高亮

系统会高亮显示未绑定的窗口以提醒用户：

- 未绑定窗口标题栏显示为红色背景
- 在任务执行后自动高亮未绑定窗口
- 高亮状态可通过"显示"菜单绑定后自动取消

## 6. 缺陷图像显示

### 6.1 缺陷图像面板

当检测到缺陷时，系统会在显示区域底部显示缺陷图像面板：

![缺陷图像面板](/Image/Display/Defect_image_panel.png)

面板功能：
- **缺陷图像缩略图**：显示检测到的所有缺陷图像
- **序号标识**：每个缺陷图像的序号
- **尺寸信息**：显示图像的像素尺寸
- **点击查看大图**：点击任意缩略图可查看原始尺寸图像

### 6.2 缺陷图像详情查看

查看缺陷图像详情：

1. 点击缺陷图像面板中的任意缩略图
2. 系统会打开大图查看器
3. 在大图查看器中可以：
   - 缩放和平移图像
   - 查看图像详细信息
   - 保存原始尺寸图像
   - 标注缺陷位置

![缺陷大图查看](/Image/Display/Defect_large_image_viewing.png)
