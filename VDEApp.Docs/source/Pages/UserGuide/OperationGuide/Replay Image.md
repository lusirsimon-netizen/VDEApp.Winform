# 仿图功能

## 1. 功能概述

仿图功能是系统提供的图像数据模拟测试工具，主要用于在离线环境下验证图像检测、分析和处理算法的正确性。该功能支持单步执行和连续执行两种模式，可帮助用户快速验证业务逻辑、调试算法参数，提高开发和测试效率。

## 2. 界面布局

仿图设置界面提供仿图参数配置和执行控制功能：

### 2.1任务配置区

![](/Image/Replay/Replay_Image_TaskSetting.png)

* **当前任务**：显示当前激活的任务名称

* **图片文件夹**：配置仿图数据源文件夹路径，支持路径浏览和选择

### 2.2仿图数据列表

以表格形式展示仿图数据信息：

![](/Image/Replay/Replay_Image_Table.png)

* **ID**：数据唯一标识

* **GUID**：全局唯一标识符

* **保存时间**：数据创建时间戳

* **数量**：图像数量

* **预期状态**：OK/NG 预期结果标记

* **状态**：当前执行状态（未运行等）

* **当前组**：所属数据组标识

### 2.3执行参数配置和操作控制区

![](/Image/Replay/Replay_Image_Opeator.png)

* **时间间隔**：设置连续执行模式下的时间间隔，单位：秒

* **运行次数**：设置仿图执行次数

* **单步运行**：单次执行仿图操作

* **持续运行**：连续执行仿图操作

## 3. 操作流程

### 3.1 基础配置流程

#### 步骤 1：进入仿图功能

![](/Image/Replay/Replay_Image_start.png)

1. 在主界面顶部功能区，点击 "仿图" 按钮

2. 系统弹出仿图设置界面

#### 步骤 2：配置数据源

![](/Image/Replay/Replay_Image_selectPath.png)

1. 在仿图设置界面，确认或修改 "图片文件夹" 路径

2. 点击路径输入框右侧的 "..." 按钮，浏览并选择包含测试图片的文件夹

3. 确认路径配置正确

#### 步骤 3：设置执行参数

![](/Image/Replay/Replay_Image_parameter.png)

1. 在 "时间间隔" 输入框中，输入连续执行模式下的时间间隔（默认值：1 秒）

2. 在 "运行次数" 输入框中，输入需要执行的次数（默认值：1 次）

### 3.2 执行操作流程

![](/Image/Replay/Replay_Image_Run.png)

#### 单步运行模式

1. 在仿图设置界面，确认所有参数配置正确

2. 双击选中需要运行的数据

3. 点击 "单步运行" 按钮

4. 系统执行一次该记录的仿图操作

5. 在主界面查看执行结果：

* 图像显示区显示当前处理的图像

* 生产数据区更新相关数据记录

* 系统日志区记录操作日志

#### 持续运行模式

1. 在仿图设置界面，确认时间间隔和运行次数设置正确

2. 点击 "持续运行" 按钮

3. 系统按照设置的时间间隔和次数连续执行仿图操作

4. 在主界面实时监控执行过程：

* 图像显示区实时更新处理中的图像

* 生产数据区动态更新数据记录

* 系统日志区实时记录运行日志

## 4. 参数说明

### 4.1 时间间隔

* **参数说明**：控制连续执行模式下两次仿图操作之间的时间间隔

* **取值范围**：正整数

* **单位**：秒

* **默认值**：1

* **注意事项**：设置过短可能导致系统负载过高，设置过长会影响测试效率

### 4.2 运行次数

* **参数说明**：控制仿图操作的总执行次数

* **取值范围**：正整数

* **默认值**：1

* **应用场景**：

  * 单步运行：执行指定次数后停止

  * 持续运行：按照时间间隔执行，达到指定次数后停止

## 5. 状态说明

### 5.1 预期状态

该状态是从图片命名格式中读取，作为图像预期状态

* **OK**：预期检测结果为合格

* **NG**：预期检测结果为不合格

### 5.2 执行状态

* **未运行**：仿图任务尚未开始执行
* **OK**：实际检测结果为合格
* **NG**：实际检测结果为不合格

## 6. 注意事项

* 确保图片文件夹中包含足够数量和质量的测试图片

* 图片格式应符合系统要求

* 图片命名应遵循系统规范，示例：`{guid}/{sn}_{yyyyMMddHHmmssfff}_{expTag}_{status}_1.{ext}`
